## Бесплатные ассеты

- **Poly Haven** — [лицензия CC0](https://polyhaven.com/license); [Fine Grained Wood](https://polyhaven.com/a/fine_grained_wood) выбран для рукояти. Загружены три 1K JPEG через официальный каталог файлов, проверены опубликованные MD5, в GLB поставлены 256². [Wood Planks](https://polyhaven.com/a/wood_planks) — кандидат на отдельную проверку пола.
- **ambientCG** — [CC0](https://docs.ambientcg.com/license/), например [Wood 049](https://ambientcg.com/a/Wood049) для более ровной мебельной древесины. Не загружался в игру: для текущей рукояти выбран более потёртый материал.
- **Quaternius** — [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html), CC0, хороший источник ретаргетинга ходьбы/поз для будущих персонажей. Не заменяет контактную анимацию пальцев и предмета от первого лица. Не импортирован.
- **Kenney** — [Impact Sounds](https://kenney.nl/assets/impact-sounds), CC0; кандидат для отдельных механических ударов, но не точная запись реза верёвки. Текущий рез использует собственный короткий Web Audio синтез со стереопозицией и отдельным финальным щелчком, только на подтверждённых контактах.

## Что внедрено

Вместо подмены ножа перед камерой — одна модель и перенос её на `GripSocket` после закрытия пальцев. Blender управляет траекториями кистей, повороты/положения читаются через Three.js `AnimationMixer`. Первое лицо использует нормальную глубину: руки не рисуются поверх коленей и комнаты. Для реза проверяется рабочий участок кромки без острия, протяжённость движения вдоль неё и длительность контакта с натянутой верёвкой. Переработка ограничена вступлением; физика дома, дождь и противники внешних проектов не импортированы.
