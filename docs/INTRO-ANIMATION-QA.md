# Вступление 100gate: хват и разрезание верёвки

Локальная точка отката: `backup/intro-animation-start` (`ed1b91a`). Архитектура игры и схема сохранений не изменены. GitHub и production не обновлялись.

## Изменения

1. Новая модель ножа из Blender: непрерывный профиль рабочей кромки, формованная рукоять и заклёпки; [CC0 Poly Haven](https://polyhaven.com/a/fine_grained_wood) для текстуры дерева. Тот же нож лежит на полу и переходит в локальный `GripSocket` после закрытия пальцев.
2. Пять независимых морфов пальцев + ладонь, вместо мгновенной подмены руки. Для исходной позы отдельная проверка выявила зазор 10–22 мм у четырёх пальцев и проникновение в области мизинца. Хват откалиброван по геометрии рукояти, а не под перспективу FPS.
3. Полностью заменено прежнее действие с точечными касаниями. До освобождения правой руки видимая связка проходит через оба запястья и к стулу. Затем левая рука остаётся в петле, а участок до стула остаётся целым. Траектория `KnifeApproach → RopeTension → SawCut → RopeBreak → StandUp` использует рабочую кромку, не остриё. На подводе нет прогресса. Нужны одновременно накопленная продольная дистанция и время контакта, после чего концы расходятся и оседают.
4. Предплечья и руки сцены находятся в мире, используют глубину и освещение комнаты. Рукава гнутся непрерывно, без стыка двух отдельных мешей на локте. Управление открывается только в конце подъёма.

## Проверки

- `verify:escape`: старт и целая связка; раскачивание и одностороннее освобождение; нож не подбирается раньше времени; закрытие пальцев; подвод без накопления; контакт, продольный рез, целая натянутая связка непосредственно перед разрывом; разлёт концов, подъём, ходьба и повторная загрузка. Зафиксировано 0.384 м суммарного продольного движения и 2.133 с в пределах порога контакта. Расстояние от рабочей кромки до оси верёвки в показанных кадрах ~3.7 мм при номинальном радиусе ~3.8 мм.
- `verify:intro-clock`: время игры, отпускание R и пауза не засчитывают завершение; после возобновления действие можно выполнить заново.
- `verify:intro -- --record`: прохождение обычными клавишами в реальном времени, камера и сюжетные переходы; `outputs/intro-animation/escape-playtest.webm` (запись браузера без аудиодорожки).
- Blender BVH, закрытая поза: 0 вершин кожи внутри деревянной рукояти и 0 пересечений пар треугольников. Измеренный минимальный зазор в областях подушечек 0.95–1.05 мм. Проверка треугольников обнаружила касания, пропущенные проверкой только вершин; экспорт доработан и перепроверен.
- `verify:episode`: полная первая глава, загрузка сохранения и мобильное управление в эмуляции Chromium iPhone 13 и Pixel 7. `verify:skill`: кадр и текстовое состояние оригинального develop-web-game клиента просмотрены.
- Снимки по фазам: `outputs/intro-animation/`; шесть ракурсов хвата: `grip-review/six-angles.png`. Вспомогательная боковая камера начала нужна для проверки верёвки за спиной, не входит в управление production-игры.

## Границы

Кисти используют морфы, а не отдельную скелетную анимацию каждой фаланги. Верёвка — ограниченная постановка с геометрическим контактом и заданной реакцией после разрезания, не симуляция волокон. Боковая камера проверки показывает игровую модель первого лица без отдельного полноценного третьеличного торса. Производительность на физическом iPhone/Android не измерялась. Не заявляется отсутствие любого пересечения во всех промежуточных кадрах.
