Задача: $ARGUMENTS

Сначала классифицируй задачу и выбери ОДНУ модель по самой дешёвой подходящей схеме:

1. **Haiku (`gate-scout`)**: поиск, чтение, "где/как это устроено", сводка логов и тестов, проверка статуса. Ничего не меняет.
2. **Sonnet (`gate-coder`)**: обычная реализация, багфикс с понятной причиной, тесты, правки интерфейса, Blender-скрипты, документация. Это вариант по умолчанию.
3. **Opus (`gate-architect`)**: только новая система или глава, неочевидный баг, крупный рефакторинг, ревью рискованного. Он даёт план, затем исполняет `gate-coder`.

Правила экономии токенов:
- Не читай много файлов сам: для разведки вызывай `gate-scout`, он вернёт только выжимку.
- Если в проекте есть `graphify-out/` (граф кода Graphify), сначала спрашивай граф (`/graphify query ...`), а не читай файлы.
- Не используй Opus, если задачу решает Sonnet.
