# Blender -> GLB
- Версия Blender: 4.5 LTS. Модели кладём в `public/assets/...` как `.glb`; исходники `.blend` в `art/` (там уже тяжёлые файлы, не раздувать без нужды).
- Перед экспортом: применить масштаб и вращение (Ctrl+A), 1 единица = 1 метр, Y-up при экспорте glTF, имена объектов и костей осмысленные и стабильные.
- Текстуры: сжимать, степени двойки, PBR (color/normal/roughness). Вес одного GLB для веба держать небольшим (`intro-native-v2.glb` в 52 МБ — плохой пример).
- После экспорта: загрузить в игре, проверить масштаб, материалы, тени. Лицензию источника записать в `CREDITS.md`.
- Blender управляется через MCP `blender` (аддон должен быть запущен в Blender, порт по умолчанию 9876).
