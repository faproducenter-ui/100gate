# Коллизии
- Физический план: `src/iso/map.ts`; декоративная геометрия коллизий не даёт.
- Новая комната: зоны, подходы к объектам, двери; все игровые цели должны быть достижимы (тест в `environment.test.ts`).
- Rapier (`@dimforge/rapier3d-compat`) есть в зависимостях, но изометрия использует собственный план; не смешивать без причины.
