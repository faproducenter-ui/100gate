# Погода и окружение
- Сейчас все комнаты закрытые; погода включается только на новых уличных локациях (двор, путь к школе №7).
- Дождь: `THREE.Points`/`InstancedMesh` капель, один draw call, привязка к камере; на `quality:low` уменьшать количество в 3–4 раза, при `reducedFlicker`/`motion:false` — без вспышек молний.
- Туман: `scene.fog` (`FogExp2`) плюс тонировка `background`; в комнатах отключать.
- Ветер: лёгкий шум для листвы, занавесок, дверей; параметры из одного объекта `weather` в `world.ts`.
- Звук: гроза и дождь через `src/iso/sound.ts` (см. `gate-audio-web`): глушить фильтром, когда игрок в здании.
- Мокрые поверхности: снижать `roughness` материала, не добавлять отдельные отражения.
- Проверка: Playwright-скриншоты в `gate-playwright-verify`, лимиты треугольников и draw calls как в `environment.test.ts`.
