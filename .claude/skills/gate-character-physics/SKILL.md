# Физика персонажа и объектов
- Основа: `movePlayer`/`canStand` в `src/iso/map.ts` (круг радиусом `PLAYER_RADIUS`, раздельные оси, подшаги ≤ .08). Не ломать: тест `state.test.ts` проверяет достижимость всех объектов.
- Реалистичность без тяжёлого движка: ускорение и торможение скорости (интегрировать `speed` в `Page.tsx` вместо мгновенного значения), скольжение вдоль стен уже есть.
- Подвижные предметы (ящик, стул, банка): отдельный лёгкий слой в `world.ts` с простой кинематикой (скорость, трение, отскок); на коллизии с планом `FURNITURE` реагировать теми же `canStand`.
- Rapier (`@dimforge/rapier3d-compat`) подключать только для декоративной физики (падающие листы, банки), не для проходимости игрока. Тела создавать лениво и освобождать в `dispose()`.
- Всегда: фиксированный шаг (1/60) независимо от FPS, предел `dt` как в `Page.tsx`; тесты на детерминизм.
