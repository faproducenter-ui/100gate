# Дизайн
- Сеттинг изометрии: административное здание, смены, журнал дежурств, операторская, приёмная. Всего планируется 100 комнат/врат по главам.
- Каждая комната: цель, один читаемый предмет/подсказка, один страх (звук/свет/намёк), выход. Страх через недосказанность, не серией скримеров.
- Новая глава начинается с короткого дизайн-документа (комнаты, предметы, задачи), потом код.
