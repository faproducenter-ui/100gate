# Первое лицо
- Включается по умолчанию (`settings.view==='fps'`), клавиша V переключает на изометрию. На тач-устройствах по умолчанию изометрия.
- Камера и «руки»: `src/iso/fps.ts` (`FpRig`): высота глаз, покачивание при ходьбе, дыхание, крен, фонарик с отставанием от взгляда, нажатие кнопки.
- Управление: `Page.tsx` (`fpOn()`): мышь через Pointer Lock (клик по экрану), WASD, Shift бег (выносливость), C присед, F фонарь, E или клик — взаимодействие; стрелки как запасное управление взглядом. Esc снимает захват и открывает паузу.
- Движение: сглаженная скорость + `movePlayer` из `map.ts` (круг R=.22, скольжение вдоль стен, двери). Шаги звучат по пройденной дистанции.
- Прицел: `IsoWorld.aimTarget` бросает луч из центра экрана по реальным предметам (`env.targets`), запас — конус вокруг прицела. Дальность: `withinReach(id,p,.7)`.
- Окружение: потолки, перемычки над дверями и достроенные низкие стены помечены `env.fpOnly` (видны только в первом лице), торцы-срезы `env.isoOnly` (только в изометрии).
- Отладка (только dev): `window.isoLook(yaw,pitch)`, `isoSetState(patch)`, `isoWorld()`.
