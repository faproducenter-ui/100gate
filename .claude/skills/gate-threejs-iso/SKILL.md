# Three.js и изометрия в 100GATE
- Точка входа: `src/App.tsx` -> `src/iso/Page.tsx`. Сцена: `world.ts`, `environment.ts`; комнаты и предметы: `env-kit.ts`, `env-materials.ts`; физический план и коллизии: `map.ts` (коллизии НЕ берутся с декора).
- Не ломать игровые идентификаторы объектов, шарниры дверей, CRT-экраны, светильники: их проверяет `src/iso/environment.test.ts`.
- Перед правкой: `npm run check` и `npx vitest run src/iso`. После: то же, затем визуальная проверка в браузере (`npm run dev`).
- Следить за бюджетом: треугольники, draw calls, число теневых источников. Диагностика: `ISO_ART_DIAGNOSTICS=1` с тестом окружения.
- Освещение и материалы: процедурные текстуры без сетевых загрузок; сторонние ассеты только с записью в CREDITS.md.
