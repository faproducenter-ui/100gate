# 100GATE — Дом, который помнит

Сюжетный хоррор от первого лица. Готов первый играбельный эпизод: 10 связанных помещений заброшенного дома, история Алексея Соколова и поиск Веры. Остальные 9 глав (90 помещений) запланированы, но ещё не реализованы. Распределение комнат: 10, 5, 6, 8, 9, 11, 12, 12, 13, 14 — всего 100.

## Запуск

Node.js 22.12+ или 24 LTS.

```bash
npm ci
npm run dev
```

Для production: `npm run build`, затем `npm start`. Сервер слушает `0.0.0.0:$PORT` (по умолчанию 3000) и раздаёт только `dist`, а не исходники. `/health` — проверка работы.

## Управление на компьютере

| Действие | Клавиша |
| --- | --- |
| Ходьба / обзор | WASD / мышь |
| Подобрать предмет, отпереть замок ключом, использовать щиток | E |
| Открыть или закрыть отпертые двери и люк рукой | G |
| Двигать мебель, раскачать стул, разрезать верёвки | Удерживать R до заполнения полосы |
| Читать / осматривать документ; положить обратно | F |
| Бег / приседание | Левый Ctrl / левый Shift |
| Прыжок / фонарь | Пробел / T |
| Пауза / продолжить | Esc |

При первом запуске нажать «Войти в дом». Браузер захватывает мышь после нажатия. Потеря фокуса автоматически ставит игру на паузу. Настройки: язык RU/EN, звук, три качества графики, чувствительность, движение головы.

## Телефоны

Горизонтальное положение. Слева — джойстик и удерживаемая кнопка бега; справа — свободный обзор пальцем, прыжок, переключатель приседания и контекстное действие. Движение мебели и освобождение работают удержанием контекстной кнопки. Шестерёнка сверху справа ставит игру на паузу и открывает настройки. Поворот в вертикальное положение показывает подсказку. Полный экран доступен там, где его поддерживает браузер; iPhone можно использовать и без него.

## Сохранения

Положение игрока, предметы, документы, двери, мебель и решённые задачи автоматически сохраняются в localStorage. Для серверной резервной копии используется `server/save-api.ts` — Railway Function на Bun и PostgreSQL. API: `GET/PUT /api/save`, `GET /health`. Параметр `DATABASE_URL` — ссылка `${{Postgres.DATABASE_URL}}` внутри Railway. Пароли базы в клиент не передаются.

Браузер генерирует случайный секрет устройства; сервер хранит только его SHA-256. Это резервная копия данного браузера, а не система аккаунтов и не автоматическая синхронизация между устройствами. При очистке данных браузера теряется и секрет доступа к копии. Серверное восстановление запускается явно в настройках. При недоступности сети игра сохраняется локально. Если само браузерное хранилище заблокировано, меню показывает это.

Публичный адрес API задан в `.env.production` через `VITE_SAVE_API`. Это адрес сервиса, не секрет. Разрешённые дополнительные адреса клиента задаются в `ALLOWED_ORIGINS` в Railway. Сервер принимает JSON до 32 KiB, проверяет формат, ограничивает частоту запросов и не выдаёт чужие сохранения.

## Публикация

- `main` хранит исходники. Railway собирает `npm run build`, запускает `npm start` и может автоматически обновляться при пуше.
- `gh-pages` хранит только собранную игру для 100gate.online. После проверки и коммита исходников выполнить `npm run build`, затем `npm run publish:pages`. Скрипт публикует обычным fast-forward push, без force. Источник Pages: `gh-pages`, `/`.
- DNS 100gate.online остаётся в Cloudflare. API и PostgreSQL работают в Railway. Отдельный старый репозиторий `100gate-backend` с тестовой оплатой не используется новой игрой; платежи не включены.

## Проверка

Сначала запустить `npm run dev` на порту 3000. Затем `npm run verify` — игровые действия, лестница, двери и ключи, документы, мебель, питание, финал главы и сохранения; затем проверка мобильного управления с двумя одновременными касаниями в Chromium. Для браузера: `npx playwright install chromium` или переменная `CHROMIUM_PATH`.

`npm run verify:cloud` проверяет работающий PostgreSQL API: запись/чтение, изоляцию устройств, валидацию и CORS. Создаёт одно техническое тестовое сохранение.

Эмуляция iPhone/Android не заменяет проверку на физических устройствах. Производительность headless SwiftShader не отражает производительность реального GPU. Старый `scripts/verify-game.mjs` относится к предыдущей версии и не используется новой главой.
