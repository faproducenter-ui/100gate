# Комнаты молчания

Браузерный 3D-хоррор-квест от первого лица: 100 комнат, 10 глав и 10 связанных расследований.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Готовая версия находится в `dist/`.

## Управление

- WASD или стрелки — передвижение (переключается в настройках).
- Мышь — обзор.
- E — взаимодействие; клавишу можно переназначить.
- F — фонарь.
- Q — бросить найденную бутылку и отвлечь Смотрителя.
- J — журнал документов.
- Esc — пауза.

## Системы

Три типа загадок (поиск, электропитание, сейф), журнал из 200 документов, противник с патрулированием/расследованием/преследованием, укрытия, шум, отвлекающие предметы, сохранение прогресса и настроек, три графических профиля и синтезированный звук.

Прогресс хранится только в localStorage текущего браузера и не синхронизируется между устройствами.

## Ресурсы

Процедурные PBR-текстуры и модели создаются локально. Дополнительно используются параметрические Three.js-ресурсы библиотеки Kimi: дверь `01-L1-0006` и настольная лампа `01-L1-0269`; исходные лицензии находятся рядом с ресурсами в `public/assets/`. Детализированная модель Смотрителя создана через Tripo API (задача `22af18a1-02e8-4564-a02a-53dc306b6072`).
